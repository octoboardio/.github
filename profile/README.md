### What is OctoBoard?

OctoBoard connects to your GitHub repos and gives your team a single pane of glass for delivery health — no Jira required.

- **DORA Metrics** — deployment frequency, lead time, change failure rate & MTTR
- **PR Velocity** — review queue, cycle time, stale PR detection
- **Risk Signals** — unassigned issues, PRs without reviewers, aging work items
- **Team Workload** — per-engineer issue & PR distribution at a glance
- **AI Board Reviews** — GPT-powered sprint summaries and risk digests
- **GitHub Projects Sync** — kanban boards with live state from GitHub Projects V2

### Get started

1. Sign in at **[app.octoboard.io](https://app.octoboard.io/)** with your GitHub account
2. Install the OctoBoard GitHub App on your org
3. Enable repos and explore your dashboard
